Version 1.0 • LinuxCNC / Probe Basic Debian-XFCE-Safe Edition (Pico RP2040 HID)

LEGEND
• Row / Col = physical matrix position on Haas panel
• Output = key or combo sent via USB HID
• Ctrl+Alt / Ctrl / Ctrl+Shift / Alt+Shift = custom safe shortcuts
• Matches Arduino v 1.0 firmware exactly (rotary A/B handled in code)

ROTARY AXIS (A/B) – Handled in Firmware
───────────────────────────────────────────────────────────────
5,3   → ROTARY- (–A / –B) → handled in sendKey()
    Shift OFF → Alt+Shift+7  = –A
    Shift ON  → Alt+Shift+9  = –B

    Shift OFF → Alt+Shift+8  = +A
    Shift ON  → Alt+Shift+0  = +B
